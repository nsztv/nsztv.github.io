NSTV

Application de télévision personnelle.

Fichier d'installation pour Fire TV et Fire Stick.

Télécharger

Sur le boîtier, dans l'application Downloader, saisissez simplement :
nsztv.github.io/n.apk

  1. Paramètres, Mon Fire TV, Options pour les développeurs : autorisez les applications inconnues.
  2. Installez Downloader depuis la boutique Amazon.
  3. Ouvrez Downloader et saisissez l'adresse de téléchargement.
  4. Installez, puis ouvrez NSTV.

Au premier démarrage, l'application vous demande l'adresse de votre fournisseur, votre identifiant et votre mot de passe. Ils restent sur votre appareil : l'application ne les envoie nulle part. Aucun identifiant n'est contenu dans le fichier.
